File Reference

Every file in the project, what it is responsible for, and when you'd open it.

Pages

index.html entry

Landing redirect.

Meta-refresh to about.html, with a clickable fallback link. No chrome. Rarely edited.

about.html · projects.html · contact.html page

Content pages.

Each is a thin <main> with <body data-page="…">. Nav/footer/theme are injected by chrome.js. Projects hosts the AI-agents tab switcher; Contact hosts the form.

blog.html page

Blog index.

Holds an empty #post-list; renderBlogIndex() fills it from posts.js. Loads posts.js before script.js.

post.html reader

Single post reader (parameterised).

Reads ?slug=…, looks it up in posts.js, fetches the matching Markdown, renders it with marked. One file serves all posts. Uses data-page="blog".

Behaviour

chrome.js shared

The shared chrome + theme engine.

Injects nav, footer, and theme switcher into every page; owns NAV, SOCIAL, THEMES, theme persistence, and nav-shrink. Edit to: change nav links, footer links, or add a theme.

script.js page

Page-content behaviour.

Smooth-scroll, blog renderers (renderBlogIndex, renderPost), the tab switcher, and the contact form handler. Edit to: change blog card markup or page interactions.

posts.js data

Blog manifest — the source of truth.

The POSTS array: one entry per post (slug, title, date, excerpt, optional tags/readMins). Edit to: publish, rename, reorder, or unpublish a post.

Content & style

posts/<slug>.md content

Post bodies, in Markdown.

One file per post; the filename's slug must match the manifest entry. posts/welcome.md is the starter post.

style.css style

The whole design system.

Tokens on :root, the risograph devices (grain, halftone, hard shadows, misregistration), and styles for every component including blog cards and post prose. The :root inks are the default-theme fallback.

Docs (this wiki)

docs/*.html · docs/wiki.css · docs/docs.js docs

The codebase wiki.

These pages. The sidebar is rendered by docs.js from the DOCS table of contents (same single-source pattern as chrome.js); layout is in docs/wiki.css, reusing the site's tokens and .post-body prose styles.

graphify-out/ generated

Knowledge-graph output.

Generated by the graphify tool — do not hand-edit. Rebuilt after code changes.

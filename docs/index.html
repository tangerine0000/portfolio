Overview

A static, build-free personal portfolio with a risograph-inspired look and a Markdown blog. Plain HTML, CSS, and vanilla JavaScript — no framework, no bundler.

What this project is

Four content pages (About, Projects, Blog, Contact) plus a Markdown-driven blog. Everything is served as static files. The only runtime dependencies are loaded from a CDN: Font Awesome (icons), Google Fonts (Inter + Space Grotesk), and marked (Markdown → HTML, blog only).

The three ideas to understand

Most of the codebase falls out of three decisions. Each one puts a lot of behaviour behind a small, single place to edit.

  • Shared chrome lives in one module. The nav, footer, and theme switcher are injected by chrome.js. A page only writes its own <main> and declares <body data-page="…">. Add a nav link once, every page updates.
  • The blog is manifest-driven. posts.js is the single source of truth. Adding a post means dropping a .md file and adding one entry — the card list, sorting, and the post page all follow.
  • Themes are data. Colour palettes are objects in chrome.js (THEMES), applied as CSS custom properties. Add a palette = add one object.

Mental model

Every page  =  static <head> + <body data-page> + <main>
                          │
              chrome.js injects nav + footer + theme button
                          │
        style.css paints it (riso tokens, grain, hard shadows)

Blog        =  posts.js (manifest)
                 ├─ blog.html  → renderBlogIndex()  → cards
                 └─ post.html?slug=x → renderPost() → fetch posts/x.md → marked

Run it locally

The blog reads Markdown with fetch(), which browsers block over file://. Serve the folder over HTTP:

python -m http.server 8000
# then open http://localhost:8000/about.html

The non-blog pages work even from file://; only the blog needs a server. On a static host (e.g. Netlify) everything works as-is.
